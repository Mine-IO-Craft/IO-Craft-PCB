# Mine IO Craft — PCB 工程设计

基于 ESP32-S3-WROOM-1 的主控板，用嘉立创 EDA 专业版（EasyEDA Pro）绘制。

## 文件

- `Mine IO Craft.eprj2` — EasyEDA Pro 工程（原理图 + PCB）
- `板框.DWG` / `板框.DXF` / `板框.SLDPRT` — 板框机械图（圆形 Ø70 mm）
- `ProLib_1pcs_2026-10-14.elibz2` — 个人库导出

## 打开方式

用立创 EDA 专业版（EasyEDA Pro）打开 `Mine IO Craft.eprj2` 即可。
